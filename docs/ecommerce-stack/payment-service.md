## 🟪 5. payment-service

## 🎯 Objetivo

Simular processamento de pagamentos via um provedor genérico.

## 🧩 Funcionalidades

- Criar pagamento para um pedido
- Simulação aleatória de aprovado/negado
- Futuro: integração Stripe/Pagar.me
